# 째깍째깍! 시간 탐험대 ⏰

초등학교 2학년 수학 **「시각과 시간」** 학습을 지원하는 반응형 웹앱입니다. 시계 바늘을 직접 움직이고, 그림이 있는 문제를 풀며, 시간 단위를 비교·변환합니다.

## 실행 주소
- 학습 앱: https://intmaker.github.io/time-adventure/
- 소스 저장소: https://github.com/intmaker/time-adventure
- 설치 없이 웹브라우저에서 실행되도록 만든 정적 웹앱입니다.

## 학습 메뉴 (총 7개)
1. **시계 놀이터·두 시계 비교**: 시침·분침 조작과 목표 시각 맞추기. '두 시계 비교 놀이'로 시작·끝 시각을 입력하거나 바늘을 움직여 차이를 **○시간 ○분 = 전체 ○분**으로 확인합니다. 12시간제 시계 한 바퀴(12시간 이내) 기준으로 계산하며, 끝 시각이 앞서면 다음 바퀴로 해석합니다.
2. **시간·분 변환 놀이터**: 시간+분 → 전체 분, 전체 분 → 시간+분 실시간 변환.
3. **시계 읽기·맞추기**: 정각·30분·5분 단위·1분 단위의 읽기/조작 퀴즈(10문제).
4. **몇 시 몇 분 전**: 주어진 시각보다 몇 분 전의 시각 계산(그림 문제).
5. **걸린 시간**: 시작과 끝 사이의 경과 시간 계산(그림 문제).
6. **시간 단위 변환**: 1시간=60분에 기초한 시간↔분 계산 문제.
7. **오전·오후와 24시간제**: 12시간제·24시간제 변환, 자정/정오 구분(12문제).

학습 메뉴 이외에 **학습 기록** 화면에서 별, 문제 풀이와 정답 횟수, 영역별 성취도를 확인할 수 있습니다.

## 이용 순서
1. 앱을 열고 탐험가 이름을 입력한 뒤 **탐험 시작하기**를 누릅니다.
2. 메뉴에서 원하는 학습을 선택합니다.
3. 문제를 읽고 시계를 움직이거나 보기 중 정답을 선택합니다.
4. 정답 시 피드백이 표시되고 퀴즈는 잠시 후 다음 문제로 넘어갑니다.
5. 힌트를 통해 다시 도전할 수 있습니다. 기록은 학습 기록 화면에서 확인합니다.

## 중요한 시간 규칙
- 시침은 '몇 시', 분침은 '몇 분'을 나타내며 큰 눈금 한 칸은 5분입니다.
- 1시간=60분. **12시 00분과 12시 0분**은 같은 시각입니다.
- 24시간제 **00:00은 자정(밤 12시)**, **12:00은 정오(낮 12시)**입니다.
- 00:15는 **밤 12시 15분(자정 15분 뒤)**입니다.
- 시간 계산에서 **시각**(언제?)과 **시간**(얼마나?)을 구분합니다.

## 구성 파일
- `index.html`: 기본 웹 화면
- `style.css`: 학습자 친화적 반응형 디자인
- `app.js`: 시계 조작, 문제 생성·채점, 시간 계산, 학습 기록
- `assets/`: 자체 제작 일러스트 및 시계 캐릭터 이미지

## 설치·개발
별도의 서버·API 키·패키지 설치 없이 `index.html`을 직접 열거나 정적 웹서버를 통해 실행할 수 있습니다. HTML/CSS/JavaScript 기반입니다.

## 개인정보 및 기록
이름·별·문제 풀이 이력은 브라우저의 `localStorage`에 저장됩니다. 서버 업로드 기능은 없습니다. 브라우저 데이터 삭제/기기 변경 시 기록이 사라질 수 있고, 공용 기기에서는 기록 초기화를 권장합니다.

## 교육적 활용과 한계
학생이 직접 시각을 조작하고 오답 후 재도전하도록 설계했습니다. 힌트와 별은 학습 보조 수단입니다. 일부 시간 비교는 **12시간제 한 바퀴 범위**로 제한되므로, 12시간 이상 또는 날짜를 넘기는 경과 시간 계산에는 사용하지 마세요. 초2 학습자료의 시계 읽기·맞추기·몇 분 전·걸린 시간·시간 단위·오전·오후 내용을 참고하였으며, 달력·개월 문제는 포함하지 않았습니다.
