# 째깍째깍! 시간 탐험대

초등학교 2학년 수학 **시간과 시각** 학습을 위한 웹앱입니다.

## 메뉴 구성
- **시계를 움직여 봐요**: 시침과 분침을 직접 움직이며 목표 시각 만들기
- **시계 퀴즈**: 시계를 읽고 정답을 고르거나, 목표 시간으로 시계 맞추기
- **시간 모험 퀴즈**: 버스·로켓 등 그림이 있는 장면 속에서 시간을 계산하는 퀴즈
- **학습 기록**: 별, 정답 횟수, 영역별 성취도 확인

## 실행 방법
1. 폴더를 다운로드합니다.
2. `index.html`을 브라우저에서 엽니다.
3. 별도의 설치나 서버 없이 바로 사용할 수 있습니다.

## 저장 방식
학습 기록과 별은 현재 브라우저의 `localStorage`에 저장됩니다.
