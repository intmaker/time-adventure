# 째깍째깍! 시간 탐험대 ⏰

초등학교 2학년 수학 **시각과 시간** 단원을 위한 무료 학습용 웹앱입니다. 시계 요정 '째깍이'와 함께 시계 읽기, 시간 계산, 일과 학습을 연습합니다.

## 학습 기능

- **시계 놀이터**: 아날로그 시침과 분침, 시각 설정 및 5분 조정
- **시계 퀴즈**: 10문제 자동 출제, 힌트, 정답 피드백
- **나의 하루**: 일정 추가·수정·삭제, 10~30분 후 시각 계산
- **시간 모험**: 경과 시간 5단계 미션
- **학습 기록**: 별, 정답률, 영역별 기록, JSON 내보내기

## 실행 방법

[사이트](https://intmaker.github.io/time-adventure/) 또는 다운로드한 폴더의 `index.html`을 브라우저에서 엽니다. 별도의 빌드, 설치, 로그인, 서버가 필요하지 않습니다.

## GitHub Pages 배포

저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**, **main**, **/(root)**를 선택하고 **Save**를 누릅니다. GitHub Pages가 켜지면 위 사이트 주소에서 실행됩니다. 배포 상태는 **Actions** 탭에서 확인합니다.

## 파일 구조

- `index.html` : 앱 진입점
- `style.css` : 파스텔 반응형 스타일
- `app.js` : 시계 조작, 퀴즈, 일정, 모험, 기록
- `assets/jjaekkagi.svg` : 캐릭터 일러스트
- `.nojekyll` : 정적 배포용

## 학습 데이터 · 개인정보

입력한 이름, 일과 및 학습 기록은 **해당 기기의 브라우저 localStorage**에만 저장되며 별도 서버에 업로드하지 않습니다. 브라우저 데이터 삭제 시 사라질 수 있습니다. 공용 컴퓨터 사용 시 학습 기록 초기화를 권장합니다.

## 교육 목적

학습자가 시각을 직접 조작하며 시침·분침의 관계를 관찰하고, 퀴즈와 실생활의 경과 시간 문제로 응용하도록 설계했습니다. 별은 참여를 돕는 보상이며 성취의 유일한 척도가 아닙니다.
